1/9 の攻撃、さらに 0 の攻撃（弱い光）まで送っていた。Q25 の _fire_at は期待値 0 の行も
候補に残していた。

■ 直し（1つの期待値の関数と、それを使う全員）
- me_device_attacks.expected_damage（全員が使う1つの期待値）: 1つの属性の力で、種族の分かって
  いるフラグがそれを免疫の 1/9 以下（IMMUNE_SHARE）にするものは 0。弱い光は HURT_LITE の無い
  種族で元から 0。ドラゴン・ブレスは属性がランダムなので各属性の 1/9 をそのまま平均する。
  属性の側は1属性1行の表にした（_ELEMENT_FLAGS（免疫・弱点）、_RESISTED（耐性と残る割合）、
  _NEEDS（そのフラグが無いと 0））。成功率は従来どおり表示の成功率・使用の成功率を掛ける。
  命中率は射撃（launcher_shot）だけにある（魔法の矢・球は命中判定が無い）。
- attack_expectation.effective: 期待値 0 の行を落とす共通の絞り込み。me_ranged_first の
  _fixed_options と _adjacent_options、quest25 の _ball_powers が使う。_beam_key は 0 の光線を
  選ばない。
- Q25 階段の段（_stairway_spent）: 階段に効く攻撃が今すぐ使えず、効く攻撃を持っている
  （充填中・使い切り）なら、11-13 の 「休んで充填を待つ」 の休み（_refill_key → _recharge_key、
  quest25:rest-recharge）。効く攻撃を何も持っていない時と休みが断られた時は従来どおり見える
  マスへ歩く（_unseen_fire）。
- _held_against（新）: 「持っている攻撃のうち、その種族に効くもの」。_area_attack_held はこれに
  種族を渡す形にした（クイル 480 は免疫が無いので振る舞いは同じ）。

■ 気付いたこと（直していない）
1. quest25 の _beam_key は bolt-or-beam を光線の割合（魔法棒20%・ロッド10%）でしか数えない。
   方向で撃つと矢（ボルト）は光線上の最初の怪物に当たるので、階段のように的が光線上の最初の
   怪物なら全部当たる。アイス・ボルトやマジック・ミサイルを過小に数えている（今回の直しで
   免疫の攻撃が 0 になったので、階段で免疫の攻撃に負けることはなくなった）。
2. breeder_area_attack._damage は (base + r) / (r + 1) で、base が 0 でも r/(r+1) が残る
   （ゲームは減衰の後に 1/9）。免疫の群れに範囲を撃つ見込みが少し残る。影響は小さい。
3. 他の段（ペン・クイル・ドルジ）の _unseen_fire は、効く攻撃が無くなった時に休まず見える
   マスへ歩く（今まで通り）。書物（_tome_unarmed）と階段だけが休む。

■ 持ち主への問い（新しい決まりが要るもの）
1. 「免疫の属性を撃たない」は Q25 だけでなく通常の戦闘の選び手にも効く（1つの期待値の関数の
   ため）。通常の戦闘で手元に免疫の属性しか無い時、今は撃たずに他の段（近接・射撃・逃げなど）に
   任せる。1/9 でも撃つべき場面（例: 逃げられない時）があるか。
