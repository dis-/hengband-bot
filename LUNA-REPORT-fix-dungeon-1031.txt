輪3  n1-c life-055（鉄獄1階、08:12〜08:13、版 bot-b6d47db93）
======================================================================
記録: latest-12h-1031/n1-c/life-055/captures/20261031-081258-loop-detected（観戦サーバーから
写したものをここへ置いた）と 20261031-081315-loop-detected。
診断の見立ての訂正: 「見えていない階段を目標にしない（in_view）」はこの件の原因ではない。
2つの階段は ascend の期限切れでも未確認でもなく、_is_upstairs_target を偽にしていたのは
_up_stairs_exit_to_wilderness（鉄獄1階の '<' は荒野の入口へ出る）。これは 70a27080b の
「荒野へは出ず帰還で帰る」決まりどおりで正しい。
本当の根: 帰還の担当の帰還の段は dungeon_level > WALK_OUT_MAX_DEPTH の時だけで、1階では
読まない。#81 の「光が無ければ帰還」は探索の一歩がある時だけなので、探索し尽くした階では
壁探し（return:search-upstairs / seek-secret-wall）と dark:backtrack の往復になった。
直し: 歩いて出られない階（全部の '<' が荒野へ出る）は深さに関係なく帰還の段を使う。
検査: 081258 の状態行 0（(18,122)、読める明るさ）。記録の探索し尽くした地図の記憶は再現
できないので、探索の一歩を無しにした（DECLARED RECONSTRUCTED）。直す前は記録と同じ
return:search-upstairs 's'、直した後は return:recall 'rd'。
残り: 081315（再起動後、暗い階段の上）は暗くて読めない。主の f2df445ed（未鑑定の {並} の
光源を付ける）は装備の最適化（較正つき）経由で、この再生（較正なし）では 081315 はまだ
return:search-upstairs のまま。帰還の担当の暗闇の回復（_empty_lantern_to_restore 等）は
未鑑定のランタンを使わない。光源の担当（unid-light の系統）で確かめてほしい。
D36（観戦 n1-c life-053、イークの洞窟1階）は今回確かめていない。イークの洞窟の入口は町なので
荒野の判定は効かず、in_view の見立てが当たっている可能性は残る。D36 は未修正のまま。

======================================================================
記録: latest-12h-1031/n1-c/life-059/captures/20261031-090148-loop-detected。
荒野にいた理由（所有者「そもそも荒野にいることがおかしい」）: 鉄獄4階のクエストから
emergency:stairs で2階へ戻り、return:explore → return:seek-upstairs → return:ascend '<'
（decision 5555、2階の [5,62]）。この地形は terrain 13 = SHAFT_UP（坑道）で2階分上がる
（floor-leaver.cpp の FloorChangeMode::SHAFT、move_num *= 2）。2階から2つ上がると鉄獄の
mindepth 1 を下回り、荒野の入口へ出た（decision 5556 で dungeon 0）。鉄獄2階へ来たのも
2階の下りの坑道（decision 5381 '>' で2階→4階）。
_up_stairs_exit_to_wilderness は level - 1 と mindepth しか比べず、坑道を普通の階段と見ていた。
直し: 判定を wilderness_exit.py に移し、上りの坑道は2階分として比べる（SHAFT の地形番号は
lib/edit/TerrainDefinitions.jsonc と一致することをテストで確かめる）。2階の普通の階段は
今どおり目標。直した後: 2階の記録の盤面で seek-upstairs も '<' も坑道へ向かわない。
断られた時（所有者「帰還を読む」）: change_wild_mode（floor/wild.cpp）は見えない起きた敵が
20マス以内にいると断り、ターンを使わない。断りの文言を見たら帰還を読み（地上なので行き先の
文字つき 'rfa'）、発動待ちの間は '5' で待つ（断られる '<' ではターンが進まず発動しない）。
理由名 wilderness:recall / wilderness:wait-recall は claim_goal_typing と town_arbiter の
survival に登録（wait-recall は cli の STATIONARY_REASONS に既にある）。
