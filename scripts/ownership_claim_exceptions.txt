# Producers that S2a could not put inside one declared claim, with the reason.
#
# SOL-DESIGN-ownership-contract.md section 6 stage S2a, pin A2: every producer
# the ownership lint can see is inside a declared claim, or is listed here with
# a one-line reason.  The target is an empty file; every line below is work
# S2b/S3 still owes.
#
# Format: ``module.py:function  # reason``.  One function per line, the name as
# the module defines it at top level (a nested function is covered by its
# host).  ``scripts/ownership_claim_lint.py`` reads this file and reports the
# uncovered sites that are *not* excused; a stale line -- a function that no
# longer exists, or that has no uncovered site left -- is an error, so the file
# cannot rot into a blanket waiver.
#
# Two kinds of entry, and nothing else:
#
# 1. LADDER DISPATCHER.  The function is not a producer: it selects among the
#    producers of several owner families and writes the winner's reason itself.
#    One ``@claims`` would declare a single owner for sites that belong to up
#    to sixteen, so the marker these need is the other spelling of design 5.1
#    -- ``with self.claim(owner, goal):`` around each branch, each with its own
#    goal.  That is a declaration, not an annotation: it allocates a claim, so
#    it belongs to the stage that turns the marker into a declaration (S2b),
#    not to this classification round.
#
# 2. RELAY.  Every site assigns a reason computed elsewhere (a caller's
#    argument, a sub-producer's return, a stored terminal).  The owner is the
#    producer that built the string, so the relay cannot declare one without
#    inventing it; it is migrated with whatever it relays.
