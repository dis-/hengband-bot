## 5. A0 — smallest first step (recommended first merge)

**Rule:** at the exact points where the driver would stop today for a V-class town reason, evaluate the HARD minimum on the visible board; if it holds, close the visit's work by handing the whole visit to the existing forced-departure owner (`repetition`) with one record line; else try the existing fundraising walk-in; else stop as today.

Policy (`policy_town.py`, ≈150–200 lines):
1. `_departure_minimum(snapshot, depth) -> dict[str, bool]` — pure, from existing predicates only: `_recall_departure_ready` (`policy.py:13423`), `_food_ready` (ordinary, `policy.py:13397`), `_light_ready` (`policy_supply.py:397`), `_cure_critical_ready`, `_teleport_ready` (`policy.py:13508/13504`), `_identify_staff_ready` (`policy_supply.py:433`), `teleport_items_safe`, `_temporary_status_clear` (`policy.py:14346`), `hp_full`, `mp_full`, `_combat_weapon_ready` (`policy.py:16416`), `home_atomic_withdraw_clear`, `not _missing_required_abilities(snapshot, depth)` (`policy_observation.py:1311`), no in-flight equipment transaction (session/restoring/owned/posted-catalog flags, `policy_equipment.py:2924–2930`), `free slots ≥ 1` (Q2). 2. `force_visit_departure(snapshot, cause) -> str | None`: if minimum holds → `_break_town_cycle(snapshot)` (`policy_town.py:5400`), `_town_blocked_reason = "repetition"`, `_town_cycle_breaks = TOWN_CYCLE_BREAK_LIMIT`, `_visit_departure_committed = cause`, append one line to `keep-running-events.jsonl` (time, turn, visit_epoch, cause, original reason, failed soft leaves, minimum values, destination/depth, entry method) → `return self._town_blocked_key(snapshot)`. Else record "hard_stop" with the failed HARD leaves → return `None` (caller keeps today's terminal).
3. Hook A (policy): first lines of `_town_blocked_key` (`policy_town.py:5545`): if `_town_blocked_reason ∈ V0` and not committed → `force_visit_departure`. - *Alternation forced-departure ↔ stuck work*: impossible while latched (`_town_special_key:5892` pre-empts producers; release at `policy.py:11674` guarded; retained latch value `policy.py:2193`). Outer fuse: residence 1500 unchanged.

- *Depart/return loop with the same stuck work*: each return is a new visit; the same stall repeats and forces departure again after ≈43 decisions (median). That is A by definition; the event line's `cause` makes it countable. No cross-visit memory in A0.
- *Posted-but-unsettled operation*: in the minimum (transaction/withdraw/restore flags) → `None` → today's H.
- *Open store UI*: `_town_blocked_key:5546–5563` already leaves first.
- *Fundraising modes*: `_break_town_cycle:5467–5496` and the `departure-no-light` branch (`:5873–5878`) are untouched.
