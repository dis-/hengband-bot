== 1. 原因 ==
感知の後の盤面は、壁・ドア・階段が見え、床は空白のまま（map_area は床を覚えない。
spell-kind/spells-floor.cpp）。探索の2つの目標がどちらも空白の床を「未探索」と読んでいた。
 a. 「歩ける床を一度は踏む」: policy_navigation.py:1724-1731（main）。訪問数 0 の見えた床を全部目標にする。
    明るい部屋の床や行き止まりの奥（隣が全部感知した壁でフロンティアでないマス）も1マスずつ踏みに行った。
    証拠: life-080 Angband 4F ターン 560863、(3,94) から '8','8' で行き止まり (1,94) へ入り、
    隠し扉の捜索 8 回と breakout で戻った（2回目のセッションの決定 237-248）。
 b. 「フロンティア」: policy.py:20434-20513（main。_is_frontier と _is_remembered_frontier）。
    隣が _marked_t に無ければ未探索。空白の通路の入口はいつもフロンティア、閉じたドアと瓦礫は隣に
    関係なく常にフロンティア。
 c. 経路は見えた床（_floor_t）の上だけを通るので、通路の先へ行くにも通路を1マスずつ見る必要があった。
費用: 4F の決定 2622 回のうち探索 2082 回、そのうち 2080 回が感知の範囲の中（感知 12 回）。

== 2. 部屋と通路の見分け方 ==
盤面に CAVE_ROOM は無い。ゲームの事実として、範囲内で地図に出ないマスは歩ける床
（REMEMBER を持たない地形は FLOOR・床に見える隠れた罠・DIRT・GRASS・GLASS_FLOOR だけで、
すべて MOVE。lib/edit/TerrainDefinitions.jsonc）。
「空白か見えた床」のうち、開いた隣が5つ以上のマス（me_powers.OPEN_SPACE_NEIGHBOURS、暗い部屋の
判定と同じ読み方。部屋の縁のマスは床の隣が5つ、ダンジョンの通路は幅1）とその開いた隣を部屋、
残りの空白を通路とする。プレイヤーが地図から読める情報だけを使う（公平）。
記録の盤面（ターン 549703）で、行き止まり (11,98)-(11,103)、西への出口 (6,97)-(6,99) は通路、
柱のある暗い部屋 (4,110) などは部屋と読まれることを試験で確かめた。

== 3. 設計と置き場所 ==
新しいモジュール src/hengbot/mapped_area.py（1か所に集めた）:
 - SOURCES: この階の訪問で感知を使った位置と半径を返す関数の表。今は me_powers.mapped_areas だけ
   （成功した map-area の使用。半径は 30、DARKNESS か不明なら 10）。巻物・ロッドを使うようになったら
   関数を1つ足すだけ。
 - refresh: 感知が増えた時だけ、その盤面から範囲（disc）と通路の空白を作り直す。クエストの階・地上は対象外。
 - MappedArea.explored: 通路の空白と、範囲内のすでに見えたマス（探索済み）。
 - MappedArea.walkable: 経路に入れてよい通路の空白（見えたマス・ぶつかって壁と分かったマスを除く）。
航行側が見るのは3か所だけ:
 - policy_navigation._build_grid_index: walkable を _floor_t に、explored を _marked_t に足す。
 - policy_navigation._plan_explore_path_pass: 範囲内のマスには「一度は踏む」の目標を作らない。
 - policy._passage_hides_ground: 範囲内の閉じたドア・瓦礫は、隣に未探索がある時だけフロンティア。
まだ見えていない部屋の空白だけが未探索として残るので、その隣（入口か中）まで行って中を見れば終わる。
暗い部屋は今までどおり明かりで見えるまで歩く（品物は明かりの中でしか見えない）。範囲の外へ続く
通路の端はフロンティアのまま残るので、残りの探索は地図の外と階段へ向かう。
降下の接近（policy_navigation._descent_step の地図の外への接近）は、盤面に無い通路の空白も
フロンティアとして読む（_is_remembered_frontier を使う。盤面にあるマスでは今までと同じ判定）。
これが無いと、感知の後に階段への接近がすぐ失効した（ターン 561131 で再現）。
階段を探す判断・クエストの階・見えた品物の拾い・危険の扱いは変えていない。感知の無い階も同じ。
