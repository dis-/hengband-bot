Magic-Eater O5 実装報告
依頼番号: #47。タスクファイルの背景参照: #116。
対象: LUNA-TASK-magic-eater-o5.txt の O5 のみ。

実装
class 16（魔道具術師）の鑑定済み魔法棒・杖・ロッドを取り込み予定品とする共通述語 is_absorption_device を追加した。
ゲーム側の src/mind/mind-magic-eater.cpp と種別定義を確認し、無の杖（sval 32）は対象から外した。
未鑑定品はこの予約の対象外。充填待ちや残量ゼロでも将来の取り込み予定は保持する。
食事候補の選択、携行食料の充填数、食料用魔道具の個数集計は mana_food_devices を共有し、取り込み予定品を除外する。
食料用魔道具2個の目標に、取り込み予定品を算入しない。Home側の目標確認も既存の集計関数を通じて同じ結果となる。
取り込み操作そのもの（O3）、購入方針、Homeからの調達方針は変更していない。食料がない場合は既存経路へ進む。
class 0 の選択順・充填数計算を維持し、既存テストの期待値は変更していない。

保守性
新しい判定を小さな magic_eater_devices.py に集約し、食事候補と在庫集計の条件重複を削減した。
識別の杖の食料控除も同じ候補集合から計算し、予約済み品の充填数を二重に差し引かない。
不要な中間変数を削除した。行数制限のあるファイルは変更していない。
新しいデータ取得関数を town producer baseline / town work review に登録し、生成マニフェストを更新した。

回帰テスト
新規7テスト。盤面には class_id=16、race_id=25（ゾンビ）、food_type=4 を設定した。
・Magic Missile と無の杖を持つ空腹時は、choose_key が無の杖を食べる。
・Magic Missile しかない場合は、空腹・衰弱・失神の各段階で既存の食料なし経路となる。
・Magic Missile と未鑑定魔道具を持つ場合は、未鑑定品を食べる。
・取り込み予定品の個数・充填数は食料集計に入らない。
・食料用魔道具が1個なら目標未達、2個なら達成となり、予約済み魔法棒は不足を埋めない。
・戦士は従来どおり充填数の多い魔法棒を食べる。述語の鑑定・種別・クラス条件も検証した。
本番の統合変更を一時的にmainへ戻すと、今回の振る舞いを固定する5テストがそれぞれ失敗することを確認し、復元した。
