return handler (11454-11464). Thus return wandering has no stuck-bound Recall
fallback before that broader detector. In the supplied captures, no carried

======

its consecutive decisions. In the general return route, after the current-tile
and reachable-upstairs checks, the existing 60-decision stuck bound now reads a
carried Recall scroll if the player is not blind or confused and scrolls are
readable (src/hengbot/policy_town.py:7411-7424). It records the existing
stuck:recall-escape reason and uses the existing Recall key builder. 60 is
below the 400-decision navigation no-progress limit.

invariant are unchanged. No new policy attributes were added, so there are no
restored-checkpoint defaults to add. The generated town-work manifest and

zero unmapped). town_structure_lint and item_sink_lint each reported zero
violations; no producer, review, item-sink, or item-intent baseline entry was
needed. The unchanged return-start census remains 36.
