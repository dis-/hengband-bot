Implementation
- Town maps now load the JSONC map variants, shared TownPreferences.jsonc legend, and TownDefinitionList.jsonc index. Town 1 uses the index's normal variant (01_Outpost_Full.jsonc).
- Town-map conditions are evaluated from QuestState values in the newest board record at startup. Missing status values default to 0, selecting the status-0 R'lyeh variant, the game's default false-condition case.
- Quest definition discovery/loading now uses only JSONC files in the migrated quests directory. Wilderness discovery/loading now uses only WildernessDefinition.jsonc. The CLI outpost help names 01_Outpost_Full.jsonc.
